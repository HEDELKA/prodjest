# DSH Browser Bridge — описание для Chrome Web Store

## English

**Let an AI agent control your real Chrome — visibly and safely.**

DSH Browser Bridge is a local bridge between an agent (DeepSeek Harness) and your
actual Chrome browser. No separate browser, no remote VPS: the agent drives the
very Chrome where the extension is installed — with your logins, cookies and profile.

- **Human-like actions.** Smooth bezier mouse trajectories with natural delays
  (`human_click`, `human_move`, `human_type`) — less likely to trip anti-bot protection.
- **Always visible.** A top banner shows "DSH agent is working on this page", a ghost
  cursor follows every mouse step, clicks flash a ring and highlight the target element.
- **Identifiable tabs.** Agent tabs are grouped into a blue "DSH-agent" group and
  titled "🤖 DSH · page title" — you can see them without opening.
- **Background mode.** Agent tabs open inactive; your focus is never stolen.
- **Local & private.** The bridge listens only on 127.0.0.1, protected by a random
  token. No data leaves your machine (see privacy policy).

Note: this extension is a developer tool for users of DeepSeek Harness. The agent
controls tabs only when you allow it and Chrome always shows the "debugging" badge
on controlled tabs. Stop control anytime from the popup.

## Русский

**Пусть ИИ-агент управляет вашим настоящим Chrome — наглядно и безопасно.**

DSH Browser Bridge — локальный мост между агентом (DeepSeek Harness) и вашим
реальным браузером Chrome. Никакого отдельного браузера: агент управляет именно
тем Chrome, где установлено расширение, — с вашими логинами, куками и профилем.

- **Человеческие действия.** Плавные траектории мыши по кривой Безье с
  естественными паузами (`human_click`, `human_move`, `human_type`) — меньше
  шансов срабатывания антибот-защиты.
- **Всё видно.** Сверху — баннер «DSH-агент работает на этой странице»,
  призрачный курсор следует за каждым движением, клики подсвечивают элемент
  кольцом и обводкой.
- **Вкладки с подписью.** Вкладки агента объединяются в синюю группу
  «DSH-агент» и называются «🤖 DSH · заголовок страницы» — видно, не открывая.
- **Фоновый режим.** Вкладки агента открываются неактивными — ваш фокус
  никто не перехватывает.
- **Локально и приватно.** Мост слушает только 127.0.0.1 и защищён случайным
  токеном. Данные не покидают ваш компьютер (см. политику конфиденциальности).

Инструмент для пользователей DeepSeek Harness. Агент управляет вкладками только
с вашего разрешения; Chrome всегда показывает плашку «debugging» на управляемых
вкладках. Остановить управление можно в любой момент из попапа расширения.
