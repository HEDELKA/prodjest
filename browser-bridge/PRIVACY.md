# Политика конфиденциальности — DSH Browser Bridge

**Кратко: расширение не собирает и не передаёт никаких данных. Всё остаётся на вашем компьютере.**

## Что делает расширение

DSH Browser Bridge — это локальный мост между агентом DeepSeek Harness и вашим
браузером Chrome. Агент отправляет команды (открыть вкладку, перейти по URL,
кликнуть, прочитать DOM, сделать скриншот) на локальный мост-сервер по адресу
`127.0.0.1:8787`, а расширение выполняет их через API `chrome.debugger` (CDP).

## Какие данные собираются

**Никакие.** Расширение:

- не собирает, не хранит и не передаёт персональные данные;
- не использует аналитику, телеметрию, рекламу и сторонние трекеры;
- не отправляет данные на какие-либо серверы, кроме **локального** моста
  на вашей машине (`127.0.0.1`);
- не передаёт данные разработчику или третьим лицам.

Содержимое страниц, которые открывает агент, обрабатывается только локально —
в контексте вашего Chrome и вашего агента. Если вы используете агента с внешним
LLM-провайдером (например, DeepSeek), данные могут уходить к этому провайдеру —
это определяется настройками агента, а не расширением.

## Локальный мост

- Сервер слушает **только** `127.0.0.1` (недоступен из сети).
- Соединение защищено случайным **токеном** (генерируется при старте сервера,
  хранится локально в файле `server/token.txt`).
- Расширение подключается только к `ws://127.0.0.1:*` с проверкой Origin.
- Управление можно полностью отключить кнопкой «Отключить управление всеми вкладками»
  или выключив/удалив расширение.

## Разрешения

- `debugger` — выполнение команд CDP (полный контроль над вкладками, на которые
  явно направлен агент). Chrome всегда показывает плашку «debugging» на управляемой вкладке.
- `tabs` — открытие/закрытие/перечисление вкладок.
- `storage` — хранение локальных настроек (URL сервера, токен, флаги).
- `tabGroups` — объединение вкладок агента в группу «DSH-агент».
