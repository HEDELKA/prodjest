# Contributing

Спасибо, что хотите помочь! DSH Browser Bridge — это «руки агента»: код должен
оставаться простым, безопасным и понятным как людям, так и агентам.

## Как помочь

- **Звёзды и репосты** — самый простой способ поддержать проект.
- **Issues** — баги, идеи, вопросы по безопасности.
- **PR** — новые команды, улучшения оверлея, документация.

## Правила

1. **Безопасность прежде всего**: не коммитьте `server/token.txt`, не открывайте
   порт наружу (только `127.0.0.1`), не ослабляйте проверку токена/Origin.
2. **Новая команда** — паттерн в `extension/background.js` → `dispatch()`:
   добавьте `case`, обновите таблицу команд в `AGENTS.md` и README.
3. **Проверяйте**: после изменения выполните `reload_extension` через мост и
   чек-лист из `AGENTS.md` (status → list_tabs → open_tab → evaluate →
   human_click → reload_extension).
4. **Коммиты** — небольшие, с понятным сообщением.
5. **UI** — держите стиль попапа (тёмная тема, градиенты, переключатели).

## Сборка

- Иконки: `node browser-bridge/scripts/gen-icons.mjs`
- Соцпревью: `node browser-bridge/scripts/gen-social.mjs`
- Магазинный/ручной ZIP: `cd browser-bridge/extension && zip -r ../release/dsh-browser-bridge.zip .`
  (на теге `v*` это делает GitHub Action автоматически).
