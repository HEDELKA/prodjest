# Workspace instructions (prodjest)

## Git и GitHub — всегда и самостоятельно
- Работать с `git` и `gh` (GitHub CLI) постоянно и самостоятельно, без вопросов: коммитить осмысленными коммитами, пушить, создавать ветки при необходимости.
- Секреты и сгенерированные токены (например, `browser-bridge/server/token.txt`) не коммитить — они в `.gitignore`.

## Проект
- `browser-bridge/` — расширение Chrome + локальный мост-сервер, позволяющие агенту управлять браузером пользователя через `chrome.debugger` (соединение только с 127.0.0.1, по токену).
