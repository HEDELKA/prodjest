DSH Browser Bridge

Chrome-расширение, которое даёт ИИ-агенту руки в вашем настоящем браузере — с плавными человеческими действиями, полной видимостью и способностью агента улучшать сам себя.

GitHub 🤖 Инструкция для агентов Релизы (ZIP)

Возможности

Всё, что нужно агенту для работы в реальном браузере.

🖱 Человеческие действия

Плавные траектории мыши по кривой Безье с естественными паузами — human_click, human_move, human_type. Меньше шансов срабатывания антибот-защиты.

👁 Всё видно

Баннер «агент работает на этой странице», призрачный курсор, кольцо и подсветка элемента при клике. Вкладки — в группе «DSH-агент» с подписью 🤖 DSH · ….

⚡ Экономия

page_snapshot отдаёт карту всех кнопок/полей/ссылок одним вызовом. Агент читает DOM, а не скриншоты.

🔁 Самоулучшение

Агент меняет код расширения и применяет его через reload_extension — замкнутый цикл без человека.

🕶 Фоновый режим

Вкладки агента открываются неактивными — ваш фокус никто не перехватывает.

🔒 Локально и приватно

Мост слушает только 127.0.0.1, защищён токеном. Данные не покидают ваш компьютер.

Быстрый старт

Три шага — и агент управляет вашим Chrome. Вводить токен вручную не нужно: расширение само получит его с локального сервера.

Запустите сервер macOS: двойной клик по start.command (или node server/index.mjs). Сервер слушает только 127.0.0.1.
Загрузите расширение chrome://extensions → «Режим разработчика» → «Загрузить распакованное» → папка extension/.
Готово Расширение само подключится к серверу и получит токен. Откройте попап — статус «подключено к мосту». Теперь агент может выполнять команды: ./bridge.sh list_tabs, human_click, page_snapshot…

Полный список команд и паттерн «добавь свою команду» — в AGENTS.md.

Почему это важно

DeepSeek Harness позиционируется как самообучающаяся машина. Это расширение — её «руки»: агент не только управляет браузером, но и улучшает код собственного управления, применяя изменения мгновенно и проверяя их сам. Никакого Playwright, MCP или отдельного браузера — только ваш реальный Chrome.
