# 🤖 DSH Telegram Bot — пульт управления задачами DeepSeek Harness

Телеграм-бот, который подключается к локальному DeepSeek Harness (Web GUI на
`127.0.0.1:3080`) по тому же HTTP/WebSocket-протоколу, что и сам GUI, и даёт вам:

- **Реалтайм-наблюдение** за выполняемой задачей — вывод агента стримится в чат
  (текст дописывается прямо в сообщении), инструменты показываются отдельными
  карточками `🛠`.
- **Остановку процесса** (`⏹ Стоп` / `/stop`) — вызывает `session.cancel`.
- **Корректировку голосом** — голосовое распознаётся **локально** (whisper.cpp,
  ничего не уходит в облако), транскрипт отправляется в контекст агента
  (`session.prompt` с режимом `steer`): текущий шаг завершается, и агент
  продолжает с учётом вашей корректировки.
- **Корректировку текстом** — обычное сообщение в чате (пока вы наблюдаете за
  задачей) тоже становится корректировкой.
- **Ответы на вопросы и запросы разрешений** агента кнопками ✅/❌.

## Как это устроено

```
Telegram  ──►  бот (Node + Telegraf, long polling)
                  │
                  ├── HTTP POST /api/session.*   (списки, создание, prompt, cancel)
                  ├── WebSocket /api/events.mux  (реалтайм-события всех сессий)
                  └── whisper-cli (локально)     (голос → текст)
                  │
                  ▼
        DeepSeek Harness host (127.0.0.1:3080)
```

Бот не трогает и не патчит DSH — он просто ещё один клиент того же API, что и
Web GUI, поэтому работает рядом с GUI, а не вместо него.

## Требования

- Node.js ≥ 20 (проверено на 24)
- Установленный DSH Web (порт 3080)
- `whisper-cli` (собранный whisper.cpp) + ggml-модель
- `opusdec` (opus-tools) — декодирование голосовых Telegram (ogg/opus):
  `brew install opus-tools`

## Установка

```bash
cd telegram-bot
npm install

# конфиг (обязательно свой токен от @BotFather):
cp config.example.json config.json
$EDITOR config.json

# модель whisper (ggml-base, ~140 МБ, мультиязычная, хорошо для русского):
bash scripts/download-model.sh
# или укажите свою в config.json: "whisperModel": "/путь/к/ggml-*.bin"
```

### config.json

| Поле | Значение |
|---|---|
| `telegramToken` | токен бота от @BotFather (**не коммитить!**) |
| `allowedChatIds` | `[]` — первый `/start` сам зарегистрирует чат; либо `["123456789"]` |
| `dshUrl` | по умолчанию `http://127.0.0.1:3080` |
| `defaultCwd` | рабочая папка для `/new` без аргументов |
| `whisperCli` | путь к бинарю whisper-cli |
| `whisperModel` | путь к ggml-модели |
| `opusdec` | путь к opusdec (обычно `/usr/local/bin/opusdec`) |
| `streamIntervalMs` | частота обновления стримящегося сообщения (мс) |
| `maxMessageChars` | предел длины одного сообщения (дальше — новое) |

## Запуск

```bash
npm start
# или
node src/index.mjs
```

Автозапуск при входе в систему (по образцу dsh-web):

```bash
bash scripts/install-autostart.sh
```

## Команды

| Команда | Что делает |
|---|---|
| `/start` | главное меню (кнопки) |
| `/tasks` | список проектов → задачи с индикаторами `🟢 активен` / `🕐 N ч назад` |
| `/watch <id>` | наблюдать за задачей напрямую (без id — выбор кнопками) |
| `/new [текст]` | создать новую задачу в `defaultCwd` (без текста — интерактивно) |
| `/stop` | остановить текущую задачу |
| `/steer текст` | корректировка текстом |
| `/mute` / `/unmute` | пауза / возобновление трансляции (команды продолжают работать) |
| `/status` | статус: за чем наблюдаете, что активно сейчас |
| `/unwatch` | отписаться от задачи |

### Голос

Пришлите голосовое сообщение, пока наблюдаете за задачей:
`🎙 распознано: …` → корректировка уходит в контекст агента (`steer`), агент
завершает текущий шаг и продолжает с учётом сказанного.

### Кнопки управления во время наблюдения

Под сообщением «📡 Наблюдаю за задачей»: `⏹ Стоп`, `🔇 Пауза`, `👁 Отписаться`.

### Разрешения и вопросы

Когда агент запрашивает подтверждение (песочница/файлы) или задаёт вопрос
(`ask_user_question`), бот присылает это в чат с кнопками ✅/❌ (вопросы — с
вариантами ответа). Ответ уходит через `/api/respond`, как из Web GUI.

## Безопасность

- Бот слушает только Telegram (long polling) и разговаривает только с
  `127.0.0.1:3080` — наружу порты не открываются.
- Доступ ограничен `allowedChatIds`; при пустом списке чат регистрируется при
  первом `/start`.
- `config.json` (токен) и `state.json` — в `.gitignore`, в репозиторий не
  попадают.
- Голос распознаётся локально — аудио не покидает машину.
